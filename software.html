Software

Open-source tools, middleware, and research artifacts developed by the UFFeScience Research Group at the Institute of Computing, UFF. They cover workflow execution, provenance data management, scheduling, and data analysis for computational science.

All repositories are public. If you use one of these tools in your research, please cite the associated paper.

FEATURED / FLAGSHIP PROJECT

AkôFlow

Actively developed

Run scientific workflows anywhere

Go · open-source workflow engine

AkôFlow orchestrates container-based scientific workflows across heterogeneous environments: Kubernetes clusters on AWS, Google Cloud, and Azure, Singularity on HPC systems, and the SDumont supercomputer at LNCC. It schedules each activity in its own container, scales them in parallel, and captures provenance data natively.

It began as an undergraduate final project and is now the group's most widely used tool. It won the Best Demo Award at SBBD 2025.

Java · Cloud workflows

SciCumulus

Workflow engine for running parameter-sweep experiments on distributed and cloud resources. This repository is a full architectural refactoring of the original UFF system, keeping its execution semantics with a modular, testable codebase.

Code Paper
Scala · Apache Spark

SAMbA-RaP

Extension of Apache Spark that runs black-box scientific programs over raw data files while capturing provenance and domain-specific data, with built-in version control of the files produced.

Code Paper

Denethor

Execution monitoring and provenance collection for scientific workflows whose activities run as AWS Lambda functions. Runs either locally or in serverless mode.

PhenoManager

PROVENANCE / OPEN SCIENCE / VISUALIZATION

Provenance, analysis, and open science

7 repositories
Python · Deep learning

DLProv

Provenance services for deep learning workflows, covering pre-processing, training, and evaluation. Supports online analysis in MonetDB, W3C PROV documents, and Neo4j graphs. Distributed as a Docker image.

Code Paper
Python · Agentic workflows

ANCHOR

Captures and analyzes the provenance of agentic workflows with an interaction-centric model of agents, tools, users, model calls, and delegations, so multi-agent runs can be traced, audited, and reproduced.

Code
TypeScript · Open science

Triptych

Links research data, source code, and publications spread across GitHub, Zenodo, OSF, and arXiv, so the full lifecycle of a scientific project can be traced and reproduced.

Code
Jupyter · Urban visualization

UTK-PROV

Provenance-aware extension of the Urban Toolkit. Records how grammar-based urban visualizations evolve during construction and stores the history in a relational database for querying.

Code
Python · Federated learning

FLARE-PROV

Federated k-means clustering with scikit-learn, using MiniBatch-style aggregation, instrumented with DfAnalyzer to capture prospective and retrospective provenance of each round.

Code
JavaScript · Federated learning

FedObserve

Web application for managing and visualizing federated learning experiments, with a t-SNE service for model inspection. Uses AkôFlow for AWS provisioning and execution monitoring.

Dataverse Dados de Rede

SCHEDULING / METAHEURISTICS

Scheduling and optimization

3 repositories
Jupyter · Confidentiality

CYCLOPS

Schedules cloud-based workflows under data confidentiality constraints. Builds a conflict graph between data files and jointly decides activity scheduling and data placement in public clouds.

Code Paper
C++ · GRASP

MemoirGRASP

GRASP-based execution strategy for multisite cloud workflows that reuses previously computed intermediate data, weighing recomputation against storage cost and letting users prioritize makespan or financial cost.

Code
Rust · Urban routing

Protector

Heuristics for the Routing of Police Vehicles in Large Urban Centers (RVP-Urb) problem: plans preventive patrol routes that maximize coverage of crime hotspots under route-length, fleet, and territorial constraints.

CellLens+

Interpretable cell-type annotation for single-cell RNA-seq data. Combines graph-based community detection with a deterministic scoring engine, plus an LLM layer that explains, but never decides, the predicted identities.

JavaScript · Phylogenetics

PhyloTreeMiner

Mining of patterns in phylogenetic trees, available as a command-line workflow and as an interactive web demo.

Benchmark built on mgBench that measures how four graph modeling transformations affect throughput, latency, CPU, memory, and storage across seven analytical queries.
